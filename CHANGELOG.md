## [Unreleased] — Phase 1a: tenancy & row-level security

### Added
- **Row-Level Security on every tenant table** — one `tenant_isolation` policy per
  table generated by `src/db/schema/rls.ts`, comparing rows against
  `current_setting('app.org_id', true)` (fail-closed: an unscoped session sees nothing).
- **`withTenantDb(orgId, fn)`** (`src/db/tenant.ts`) — the only sanctioned tenant
  data-access path. Validates the org id, wraps work in one transaction, applies
  `SET LOCAL` (via `set_config(..., false)`) so the scope reverts at commit.
- **Real-PostgreSQL integration suite** (`tests/integration/`, ADR-0011) — 13 tests
  on a live server started by `embedded-postgres`. Proves, not assumes:
  - read isolation, including reading another tenant by exact id (0 rows);
  - unscoped app role sees 0 rows on **all** tenant tables (fail-closed);
  - cross-tenant INSERT rejected (SQLSTATE 42501);
  - cross-tenant UPDATE and DELETE affect 0 rows, data untouched;
  - composite FK `product_prices → products(id, org_id)` rejects a foreign-tenant price;
  - one open session per (register, currency); CDF/USD coexist; handover after close.
- **CI job `test-integration`**, wired into the `ci-ok` gate.
- ADR-0011 (real-DB integration tests); ADR-0001 updated to reflect the implemented
  `withTenantDb` and the SQLSTATE 42501 / FK-ordering findings.

### Changed
- `products(id, org_id)` is now a UNIQUE **constraint** (not a unique index) so the
  generated migration orders the constraint before the composite FK that references it.
- Migration regenerated (`0000_daffy_arachne.sql`) — still 7 tables, 12 FKs, now with
  7 RLS policies and 1 inlined unique constraint.
- `client.ts` clarified as platform/migration-only; tenant access goes through `tenant.ts`.
- `.env.example` documents the optional tenant-pool tuning keys (commented, no values).
- `package.json` — dev deps `embedded-postgres`, `pg`, `@types/pg`; `engines.node >= 20.9`.

### Fixed
- Generated migration would have failed on a fresh database (FK emitted before its
  backing unique index). Now passes on a clean server.

### Test evidence
`pnpm typecheck` ✅ · `pnpm lint` ✅ · `pnpm test` **28/28** (15 unit + 13 real-DB)
· `pnpm build` + `pnpm pwa:guard` — re-verified with the full gate below.

## [Phase 0] — Foundations and verification (committed `df4afaf`)

### Added
- Next 16 App Router + TypeScript 5.9.3 (strict) + Tailwind 4 + ESLint 9 scaffold.
- Drizzle schema: 7 tables (organizations, branches, categories, products,
  product_prices, cash_registers, cash_sessions), 5 enums, normalized dual-currency
  pricing (ADR-0005), cash-register/session model (ADR-0006).
- `src/lib/money.ts` (exact minor-unit arithmetic) and `src/lib/prices.ts`
  (`resolvePrice` / `findMissingPrice`, `PriceMissingError`) with 15 unit tests.
- PWA scaffold: Serwist service worker, manifest, icons, `pwa:guard` byte check.
- CI workflow (typecheck, lint, secrets-guard, test-unit, build, `ci-ok`),
  CODEOWNERS, and the documentation set under `docs/` + ADRs 0001–0010.
